My First Steps in Web Development

August 11, 2026

I recently built my first real HTML project — a Cat Photo App. It sounds simple, but it taught me more than I expected.

At first, I didn't even realize an image could be clickable. I found out that wrapping an <img> tag inside an <a> tag turns the whole image into a link — no extra text needed.

Every small mistake taught me something. A single missing closing bracket once broke an entire section of my code.

Here's a snippet from my project:

<a href="https://freecatphotoapp.com">
  <img src="cat.jpg" alt="A cute cat">
</a>
What's next for me

I'm planning to learn CSS next, so I can start styling my pages instead of just structuring them. After that, JavaScript — and eventually, cybersecurity.
